# Game design

Mannequins move while unobserved. Observation transitions green → orange grace → red. Actual movement above a configurable jitter threshold raises integer suspicion. Discovery captures the player into the warehouse without destroying identity. Teammates rescue, finish objectives and escape before dawn.

Delivery order: local primitive gameplay → test all systems → Fusion → multiplayer tests → PlayFab accounts/lobbies → art → polish.

Resolve the brief's threshold ambiguity during detection: proposed discovery on the next valid movement event after reaching threshold, with a configurable immediate-discovery alternative. No rule has been implemented yet.
