# Testing

Run `python3 Tools/check_scaffold.py` and `python3 Tools/test_unity_runner.py`
for repository/tooling checks. They do not replace Unity tests.

Run `python3 Tools/unity.py edit` then `python3 Tools/unity.py play` for Unity
EditMode/PlayMode suites. The runner rejects stale, empty or failed XML. Logs and
XML are in ignored `TestResults/`. Use `python3 Tools/unity.py build` for Windows.
